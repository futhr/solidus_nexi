# Changelog

## 0.1.0.alpha.1

- Rebuilt the extension under the renamed `solidus_nexi` / `SolidusNexi` identity.
- Replaced the legacy ActiveMerchant DIBS gateway with hosted Nexi Checkout.
- Added durable operations, capture/refund idempotency, authenticated webhook deduplication, and retrieval-based reconciliation.
- Added Solidus 4.7/4.6 and Ruby 3.2+ development targets.

Historical `spree_dibs` releases are preserved through repository tags, including `v2.1.0`.
